# 发布说明与检查

## 这份目录的用途

这是从运行项目中按文件名单复制的独立展示版，未复制原项目历史。包含业务源码、测试、虚构数据演示、通用部署模板与求职材料。

仓库地址：https://github.com/become-better1/ai-inventory-ops-assistant 。公开内容来自本展示目录；后续同步仍需排除私人运行文件。当前没有 LICENSE，不代表已授予他人自由使用许可。

## 已排除的内容

- 正式数据库、迁移包、本地和云端备份。
- API 凭据、个人隧道 ID、组织和工作区 ID、服务器地址。
- 私人截图、绝对用户目录、历史部署记录及个人启动脚本。
- 虚拟环境、下载工具和运行日志。

test_mcp.py 中的 `C:/other.sqlite3` 是用于拒绝任意数据库路径的测试输入，不是作者实际路径。示例配置中的 REPLACE_WITH_YOUR_TUNNEL_ID 需要使用者自行替换。

## 发布前完成的人工步骤

1. 核对作者 Hao He、项目描述和个人职责表述。
2. 运行演示与测试，检查实际结果；CI 运行前不展示通过徽章。
3. 选择是否授权他人使用源码，并确定合适的许可证。
4. 后续更新时只提交本展示目录中的内容，确认变更清单后再同步。
5. 可选：录制专用演示数据的视频，发布后将真实链接加入 README。

不要把实际运行项目整个压缩上传。即使工作目录已删除敏感文件，如果曾提交到 Git 历史，仍需检查历史；本展示目录目前不包含原仓库历史。

## 展示边界

- 130 项测试是工程验证，不是覆盖率、吞吐量或企业提效指标。
- 已配置开机启用并验证服务重启，未进行整机重启实测。
- 云端每日备份与一次本机异地快照下载已验证，自动异地备份和保留策略尚未实现。
- 未来集群巡检与告警分析仅是方向，目前没有相关生产接入。
