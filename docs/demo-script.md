# 2～3 分钟演示脚本

全程使用 `portfolio_demo.py` 的虚构物品及临时数据库。录屏关闭私人标签页，不展示云控制台、凭据或真实购买记录。未录制的视频不得添加虚构链接。

| 时间 | 画面 | 讲解重点 |
| --- | --- | --- |
| 0:00–0:20 | README 的问题与架构图 | 我从大数据运维出发，实践如何把 AI 接入可控工具并持续运行。当前场景是个人物品管理。 |
| 0:20–1:00 | 运行 portfolio_demo.py | 未知金额可以先记；重复请求不会增加库存；补录金额修改原记录。 |
| 1:00–1:30 | 演示输出与对应代码 | 部分退货会同步库存和净支出，撤销前检查版本。 |
| 1:30–2:00 | 测试结果与 test_mcp.py | 验证业务之外，还通过真实 MCP 客户端和子进程验证协议。展示本次真实运行结果。 |
| 2:00–2:30 | deploy 服务文件与维护文档 | 解释进程守护、健康/就绪检查、备份和离线恢复。 |
| 2:30–2:50 | 可靠性文档的限制与待办 | 无生产提效数据、无负载测试；下一步可做运维日志分析，但目前未实现。 |

可选的 ChatGPT 交互演示，应连接专用演示数据库和独立隧道，避免改动个人正式库。同一个隧道不要同时运行两份不同数据库。
